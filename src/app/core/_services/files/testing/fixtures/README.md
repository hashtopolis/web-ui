# xz fixtures for the file preview specs

Node cannot write xz, so the xz test inputs are committed. Each `<sample>.txt.xz` holds the text the
sample of the same name in `file-preview-formats.spec.ts` stands for, generated by `../preview-text.ts`.

`random-hex-5000.txt.xz` is written in 8 KiB blocks, so it is a multi-block file as `xz -T0` writes
them. The others are single-block.

The `numbered-10.<variant>.txt.xz` files hold `numberedLines(10)` written with options hashcat
reads. The preview's xz decoder (htp-decompress) supports all of them but `x86-delta`, a chain of
two filters in front of LZMA2, where it allows one.

Regenerate them from this directory with Node 24 or later (which runs TypeScript directly) and the
`xz` command-line tool:

```bash
node --no-warnings -e "import('../preview-text.ts').then((m) => process.stdout.write(m.numberedLines(10)))" | xz -9 --check=crc64 > numbered-10.txt.xz
node --no-warnings -e "import('../preview-text.ts').then((m) => process.stdout.write(m.numberedLines(40)))" | xz -9 --check=crc64 > numbered-40.txt.xz
node --no-warnings -e "import('../preview-text.ts').then((m) => process.stdout.write(m.numberedLines(80)))" | xz -9 --check=crc64 > numbered-80.txt.xz
node --no-warnings -e "import('../preview-text.ts').then((m) => process.stdout.write(m.numberedLines(1000)))" | xz -9 --check=crc64 > numbered-1000.txt.xz
node -e "process.stdout.write('a\n'.repeat(4194304))" | xz -9 --check=crc64 > a-lines-4194304.txt.xz
printf '' | xz -9 --check=crc64 > empty.txt.xz
node --no-warnings -e "import('../preview-text.ts').then((m) => process.stdout.write(m.randomHexLines(5000)))" | xz -9 --check=crc64 --block-size=8KiB > random-hex-5000.txt.xz
node --no-warnings -e "import('../preview-text.ts').then((m) => process.stdout.write(m.numberedLines(10)))" | xz -9 --check=crc32 > numbered-10.crc32.txt.xz
node --no-warnings -e "import('../preview-text.ts').then((m) => process.stdout.write(m.numberedLines(10)))" | xz -9 --check=none > numbered-10.check-none.txt.xz
node --no-warnings -e "import('../preview-text.ts').then((m) => process.stdout.write(m.numberedLines(10)))" | xz -9 --check=sha256 > numbered-10.sha256.txt.xz
node --no-warnings -e "import('../preview-text.ts').then((m) => process.stdout.write(m.numberedLines(10)))" | xz --check=crc64 --lzma2=dict=96MiB > numbered-10.dict-96mib.txt.xz
node --no-warnings -e "import('../preview-text.ts').then((m) => process.stdout.write(m.numberedLines(10)))" | xz --check=crc64 --x86 --lzma2=preset=6 > numbered-10.x86.txt.xz
node --no-warnings -e "import('../preview-text.ts').then((m) => process.stdout.write(m.numberedLines(10)))" | xz --check=crc64 --x86 --delta --lzma2=preset=6 > numbered-10.x86-delta.txt.xz
```
