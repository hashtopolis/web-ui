# xz fixtures for the file preview specs

Node cannot write xz, so the xz test inputs are committed. Each `<sample>.txt.xz` holds the text the
sample of the same name in `file-preview-formats.spec.ts` stands for, generated by `../preview-text.ts`.

`random-hex-5000.txt.xz` is written in 8 KiB blocks, so it is a multi-block file as `xz -T0` writes
them. The others are single-block. Regenerate them from this directory with Node 24 or later (which
runs TypeScript directly) and the `xz` command-line tool:

```bash
node -e "import('../preview-text.ts').then((m) => process.stdout.write(m.numberedLines(10)))" | xz -9 --check=crc64 > numbered-10.txt.xz
node -e "import('../preview-text.ts').then((m) => process.stdout.write(m.numberedLines(40)))" | xz -9 --check=crc64 > numbered-40.txt.xz
node -e "import('../preview-text.ts').then((m) => process.stdout.write(m.numberedLines(80)))" | xz -9 --check=crc64 > numbered-80.txt.xz
node -e "import('../preview-text.ts').then((m) => process.stdout.write(m.numberedLines(1000)))" | xz -9 --check=crc64 > numbered-1000.txt.xz
node -e "process.stdout.write('a\n'.repeat(4194304))" | xz -9 --check=crc64 > a-lines-4194304.txt.xz
printf '' | xz -9 --check=crc64 > empty.txt.xz
node -e "import('../preview-text.ts').then((m) => process.stdout.write(m.randomHexLines(5000)))" | xz -9 --check=crc64 --block-size=8KiB > random-hex-5000.txt.xz
```
